## 一、12 个音符键（走 **J13** 排针）

**J13** 是板上的 2×20（40P）SDRAM 扩展座。**不插 SDRAM 子板时引脚悬空，可作 GPIO 使用。**

⭐ **布局是"钢琴式"：一排 7 个白键 + 一排 5 个黑键**（正好对应排针的两行）。

| 行 | 键 | 音 | 频率(Hz) | `base_note` | **BGA** | 官方网络名 | Verilog 信号 |
|---|---|---|---|---|---|---|---|
| **白键排** | 键 0 | C4 (Do) | 261.63 | 36 | **C18** | SDRAM0_A3 | `Key_note[0]` |
| | 键 1 | D4 (Re) | 293.66 | 38 | **D20** | SDRAM0_A10 | `Key_note[1]` |
| | 键 2 | E4 (Mi) | 329.63 | 40 | **F16** | SDRAM0_RAS | `Key_note[2]` |
| | 键 3 | F4 (Fa) | 349.23 | 41 | **F13** | SDRAM0_DQM1 | `Key_note[3]` |
| | 键 4 | G4 (Sol) | 392.00 | 43 | **D14** | SDRAM0_A6 | `Key_note[4]` |
| | 键 5 | A4 (La) | 440.00 | 45 | **D17** | SDRAM0_A11 | `Key_note[5]` |
| | 键 6 | B4 (Si) | 493.88 | 47 | **B20** | SDRAM0_DQ10 | `Key_note[6]` |
| **黑键排** | 键 7 | C#4 | 277.18 | 37 | **E19** | SDRAM0_A1 | `Key_note[7]` |
| | 键 8 | D#4 | 311.13 | 39 | **F15** | SDRAM0_BA0 | `Key_note[8]` |
| | 键 9 | F#4 | 369.99 | 42 | **E16** | SDRAM0_A4 | `Key_note[9]` |
| | 键 10 | G#4 | 415.30 | 44 | **A18** | SDRAM0_A8 | `Key_note[10]` |
| | 键 11 | A#4 | 466.16 | 46 | **B21** | SDRAM0_DQ8 | `Key_note[11]` |

⚠️⚠️ **键号不是按音高顺序排的**（键 7 是 C#4，音高上夹在键 0 与键 1 之间）。
**这是刻意排的"钢琴布局"，不要"顺手理顺"成音高递增。**
代码里的逐键对照表在 `note_map.v` 头部。

> ⚠️ **2026-10-13 由「10 键五声音阶」改成「12 键十二个半音」。**
> 旧版是 `C D E G A` 两个八度（10 键），选五声的理由是"一排裸按键手一抓就是相邻键，
> 而自然音阶里相邻键是全音甚至半音、拍频正好落在人耳最粗糙的区间、多键一起按会嗡嗡成一团。
> 五声没有小二度、没有三全音，任意组合都协和（210 个四键组合里偏粗糙的从 24 个降到 1 个）"。
> 改成完整八度十二个半音后**弹什么旋律都行**（旧排法弹不了 Fa/Si），代价是回到"相邻键可能是半音"。

> ⚠️⚠️ **`B17` = `SDRAM0_CLK`，是全局时钟脚，本表刻意不用它。**
> 早期草稿里曾把某个键排到 B17，**已换成 B20**。改这份表时**务必避开 B17**。

**接线**：按键一端接 J13 对应脚，另一端接 **GND**（板上任意 GND 脚）。
**不需要外接电阻** —— FPGA 内部上拉已配置（`PULL_MODE=UP`），按下拉到 GND 即为低电平。

## 三、★ 五只旋转编码器（2026-10-13：1 只 → 5 只）

**接法全部一样**：A、B、SW 三根信号线直连 FPGA，**公共端 C 接 GND**。
**不需要外接上拉电阻**（`PULL_MODE=UP`）。
**方向约定**：若顺时针转反而变小，把 **A / B 两根线对调**即可（**代码不用改**）。

### ① EC11 —— 音量 + 音色（沿用，未变）

| 信号 | BGA | 用途 |
|---|---|---|
| A 相 | **A13** | 音量（旋转） |
| B 相 | **C13** | |
| SW | **C14** | 短按 **切音色**（长笛→钢琴→管风琴→弦乐） |

> ⭐ **长按现在是空的** —— 原来"长按切效果器类型"的 `fx_ctrl` **已退役**
>（效果器改为各自的编码器开关），所以长按不再有任何动作。

### ②③④ 三个效果器各一只（旋转 = 调该效果器的档位；SW = 开 / 关）

| 效果器 | A 相 | B 相 | SW | 旋转调什么 |
|---|---|---|---|---|
| **延迟** | **C19** | **D19** | **C20** | 80 / 160 / 240 / 320 ms |
| **混响** | **F19** | **E17** | **F14** | **4 档线性阶梯**：`g = 0.5/0.75/0.875/0.9375`（τ ≈ 50/101/202/405 ms）；**上电 = 档3（最湿）** |
| **合唱** | **D16** | **D15** | **A19** | 深度 4 档 |

**用法**：按一下 SW ⇒ 打开这个效果器；**再按一下 ⇒ 关掉**。
旋转只改**这个效果器自己**的档位（三者**互不干扰**）。
⭐ 档位**两端夹紧**：转到底/到顶就**停住**，不会绕回另一头。

> 📌 这与草稿里"三个效果器共用一个编码器、按键切换"**相反** ——
> 2026-10-13 你最终定的是**反过来**：**效果器各一只（三个）**、**表情共一只**。
> 引脚编号没变，只是**角色对调**了（把原"滑音/颤音/振音"那三只给了三个效果器）。

> ⚠️ **没有档位显示**：`LEDs[7:6]` 显示的是"**亮着几个效果器**"（`~fx_sel`），
> **不是档位**。判断当前在第几档只能靠"**转到端点再数格子**"（档位两端夹紧 ⇒ 总能归位）。
> 例：混响上电 = 档3（最湿）；往一个方向转到转不动 = 端点，再反向数。
> 📌 **下一步做显示屏时解决这个问题**（见本文档 §九）。

### ⑤ 表情一只（SW = 循环切维度；旋转 = 调**当前那个维度**的档）

| 信号 | BGA | 用途 |
|---|---|---|
| A 相 | **C17** | |
| B 相 | **B18** | |
| SW | **A21** | 循环切换：**关 → 滑音 → 颤音 → 震音 → 关** |

旋转只调**当前显示的那个维度**的档位（4 档，两端夹紧）。
⭐ **三个维度各存一份档**：切到别的维度再切回来，**原来的档位还在**。

> ⚠️ **为什么保留"关"这一档**：没有它就**没法把表情关掉**。
> ⚠️ 表情的档位与效果器的档位是**两套**，互相独立。

### 引脚总表（24 个脚，**全部是 J13/SDRAM 公共脚**）

| 编码器 | A 相 | B 相 | SW |
|---|---|---|---|
| 延迟 | C19 `A2` | D19 `A0` | C20 `BA1` |
| 混响 | F19 `CS` | E17 `CAS` | F14 `DQM0` |
| 合唱 | D16 `WE` | D15 `A5` | A19 `A7` |
| 表情 | C17 `A9` | B18 `A12` | A21 `DQ9` |

（`Ax` = `SDRAM0_Ax`，`BAx` = `SDRAM0_BAx`，`DQx` = `SDRAM0_DQx`）

⭐ **已逐脚对过官方引脚文件**：**没有一个是全局时钟脚、没有一个是 CPU/SSPI 双功能脚** ✓
⚠️ 因此 **J13 排针在使用期间绝对不能插 SDRAM 子板**（否则引脚直接冲突）。

## 五、LED（低电平点亮，输出 0 = 亮）

| 信号 | BGA | 用途 |
|---|---|---|
| `LEDs[0]` | T18 | 音色闪烁（兼心跳）：钢琴慢闪 ~1.5Hz ／ 长笛中闪 ~3Hz ／ 管风琴快闪 ~6Hz ／ 弦乐 ~0.75Hz |
| `LEDs[3:1]` | R18 / R17 / P16 | 八度状态（图案 = 八度+2 的二进制） |
| `LEDs[5:4]` | U21 / T21 | **表情维度**：00=关 01=滑音 10=颤音 11=震音 |
| `LEDs[7:6]` | R19 / P19 | **亮着几个效果器**：00=全关 01=1 个 10=2 个 11=3 个（`~fx_sel`） |

> ⚠️ `LEDs[4..7]` 是**双功能脚**（CPU/SSPI），必须在 Gowin 里打开
> 「Use SSPI/CPU as regular IO」，否则这几个脚拿不到：`impl/*_process_config.json` 里
> `"CPU": true, "SSPI": true`（`"MSPI"` 保持 false，启动路径不动）。
> **照官方例程 `TangMega-138K-example-main/pmod_led` 来**（它用的就是这 8 个焊盘）。
>
> ⚠️ **`LEDs[7:6]` 显示的是"个数"，不是"哪一个"**：三个效果器是**各自独立的开关**，
> 两位显示不下三个状态 ⇒ 2026-10-13 起改为**亮着几个**（`assign LEDs[7:6] = ~fx_sel`）。
>
> ⚠️ **8 个灯已经排满，没有档位显示**：音色(1) + 八度(3) + 表情(2) + 效果器个数(2) = 8。
> 档位只能靠"转到端点再数格子"判断。**下一步上显示屏解决**（见 §九）。

## 八、快速核对（烧录后）

**不接线也能测**：用一根杜邦线，一头插 J13 对应脚，另一头**碰 GND**，就能听到对应音。

| 依次碰 | C18 | D20 | F16 | F13 | D14 | D17 | B20 | E19 | F15 | E16 | A18 | B21 |
|---|---|---|---|---|---|---|---|---|---|---|---|---|
| 应该听到 | **C4** | **D4** | **E4** | **F4** | **G4** | **A4** | **B4** | **C#4** | **D#4** | **F#4** | **G#4** | **A#4** |
| 行 | 白 | 白 | 白 | 白 | 白 | 白 | 白 | 黑 | 黑 | 黑 | 黑 | 黑 |

**编码器**（接好后）：

| 操作 | 期望 |
|---|---|
| 按「延迟」编码器 SW | 听到延迟回声；`LEDs[7:6]` = 01（只亮 LED6） |
| 再按一次 | 关掉；`LEDs[7:6]` = 00（两盏都灭） |
| 旋转「延迟」 | 回声间隔 80→160→240→320 ms 逐档；**到头停住不绕回** |
| 按「混响」SW + 旋转 | 尾巴由短到长（4 档） |
| 「表情」按 SW | `LEDs[5:4]` 循环 00→01→10→11（关→滑音→颤音→震音） |
| 「表情」旋转 | 当前维度的深度变；**切到别的维度再切回来，档位还在** |
| 旋转 EC11 | 音量变化（与原版一致） |
| 短按 EC11 | 切音色（`LEDs[0]` 闪速跟着变） |

**若某个键不出声/音不对** → 引脚号有偏差，逐个排查（先对 `top.cst`）。

## 九、显示屏（📌 下一步，**引脚尚未分配**）

> ⭐ **2026-10-18：音频部分已全部完结**（阶段 1~11 全部上板验收）。
> 下一步是做**显示屏**；本文档届时需要新增一节"显示接口引脚"。

**现状**

| 项 | 状态 |
|---|---|
| `top.cst` 中的显示引脚 | **一个都没有** |
| 可用于显示的引脚 | J13 上未被占用的 `SDRAM0_DQ` 若干（见 §六）；**不要用 `SDRAM0_CLK`（B17）** |
| 已被占用的双功能脚 | `LEDs[4..7]`（U21/T21/R19/P19，CPU/SSPI）—— 已作 LED 用，不要再复用 |

**选型前必须先定的四件事**

1. **屏型与接口**：SPI（ILI9341 类）/ RGB 并口 / MIPI？
2. **分辨率与色深** → 直接决定引脚数与像素时钟。
3. **显示内容**：音名 / 八度 / 音色 / 表情维度 / 三个效果器开关 / **混响 4 档** / 电平表？
4. **时钟域与扇出**：
   - ⚠️ **显示逻辑不得增加 `sample_strobe` 的负载** —— 那条网贴着 LW 阈值，
     多接负载就会被提升成 LW 全局时钟 ⇒ **整板不跑、工具零报错**（见 §七 第 5 条与`软件方案` §4.0）；
   - 显示应使用**独立时钟域**（或至少在 `sys_clk` 上自产节拍），**不要**去挂音频的节拍信号；
   - 若屏需要高速像素时钟（如 25 MHz），要先确认它能走 **PLL / 全局时钟**，别让综合器拿普通网去当它。

**改动流程（沿用本工程铁律）**

```
改 top.cst 引脚 → run syn; run pnr
→ grep -A25 "Global Clock Signals" impl/pnr/*.rpt.txt | grep LW   ← 必须无输出
→ 位流时间必须比所有 src 新
→ 上板
```
